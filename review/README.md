# Informed game review

The solution folder contains a separate complete MakeCode project for reviewing gameplay. It is not the tutorial starter and is not a learner journey. The student tutorial begins with comment-only main.ts and template resources with an empty on-start block and title comment in the native editor. No executable learner code is supplied in those starter resources. To inspect the solution, use its own pxt.json, main.ts and engine.ts together in a separate disposable review project.
